# VR-урок

Интерактивные VR-комнаты по предметам для Meta Quest (1, 2, 3), с тестами и страницей учителя. Работает в браузере шлема через WebXR. Внешних библиотек нет; после первого открытия всё работает без интернета.

Адрес: https://cosmo818.github.io/vr-lesson/
Учителю: https://cosmo818.github.io/vr-lesson/teacher.html (PIN по умолчанию 1234)

## Как проходит урок

1. Учитель заранее добавляет учеников (на стартовом экране или во вкладке «Ученики»).
2. Ученик выбирает своё имя и нажимает «Войти в VR».
3. Он попадает в холл, а оттуда через двери или кнопки идёт в комнаты.
4. В каждой комнате можно изучить экспонаты (за каждое открытие +2 балла) и пройти тест из 5 вопросов. Вопросы подбираются по классу: 1–4, 5–7 или 8–11.
5. По истечении таймера (по умолчанию 8 минут) появится напоминание. Ученик выходит из VR кнопкой «Завершить» в меню, затем шлем передают следующему.

Для группы из 5 человек на 45-минутный урок подходит 7–8 минут на ученика. Время меняется в разделе «Данные и настройки».

## Комнаты

| Комната | Что внутри |
|---|---|
| Холл | Двери в комнаты, разминка: взять и бросить предметы, красная кнопка |
| Математика | 8 фигур (5 тел Платона, шар, цилиндр, конус), формула Эйлера; доска графиков y = kx + b, ax² + c, a·sin(kx), a/x с настройкой параметров |
| Физика | Гравитация Земли, Луны, Марса, Юпитера и невесомость; опыт с падением шара и сравнение с формулой; маятник с изменяемой длиной и измерением периода |
| Химия | Таблица Менделеева (20 элементов) с фактами; реактор: собрать H₂, O₂, N₂, H₂O, CO₂, CO, CH₄, NH₃, H₂O₂ из атомов |
| Космос | Солнечная система с Луной, весы «сколько я вешу на других планетах», запуск ракеты |

## Управление

- Стик вперёд и отпустить: телепорт. Стик вбок: поворот на 30°.
- Курок по лучу: нажать кнопку, выбрать предмет или дверь.
- Хват или курок рядом с предметом: взять. Отпустить в движении: бросок.
- Кнопка A, B, X или Y: меню (комнаты, время, завершение).

Без шлема (на ПК) включается режим экрана: мышь (зажать) для осмотра, W A S D для ходьбы, щелчок или пробел для выбора, E (держать) чтобы взять, M для меню.

## Где хранятся результаты

Всё сохраняется в браузере того устройства, на котором проходят урок (в шлеме). Страница учителя показывает данные этого же браузера:
- смотреть прогресс можно прямо в шлеме, открыв teacher.html;
- для переноса на ПК: в шлеме «Данные и настройки» → «Скачать данные», на ПК тот же раздел → «Загрузить файл». Повторы при загрузке пропускаются.

Синхронизации через интернет нет. Для неё понадобится сервер; это следующий шаг, если нужен.

## Файлы

- `index.html`, `css/style.css`, `js/app.js`: стартовый экран и сеанс ученика
- `js/engine.js`: движок (WebGL2 + WebXR, панели, физика, ввод)
- `js/rooms.js`: комнаты и тесты
- `js/data.js`: вопросы и учебный материал. Чтобы добавить вопрос, допиши его в конец нужного списка: верный ответ всегда первый, при показе ответы перемешиваются. Не меняй порядок существующих вопросов, иначе статистика «сложных вопросов» перепутается.
- `js/store.js`: хранение учеников и результатов
- `teacher.html`: страница учителя
- `sw.js`: офлайн-кэш. При изменении набора файлов увеличь версию `V`.
