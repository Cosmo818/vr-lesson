# VR-урок

Интерактивные VR-комнаты по 8 предметам для Meta Quest (1, 2, 3), с тестами по классам, конструктором тестов и страницей учителя. Работает в браузере шлема через WebXR. Внешних библиотек нет; после первого открытия всё работает без интернета. Результаты синхронизируются с сервером на Raspberry Pi, если он подключён.

- Для учеников: https://cosmo818.github.io/vr-lesson/
- Для учителя: https://cosmo818.github.io/vr-lesson/teacher.html (PIN по умолчанию 1234)

## Комнаты

| Комната | Что внутри |
|---|---|
| Холл | Двери в 8 комнат, разминка (взять и бросить, красная кнопка), общие тесты учителя на задней стене |
| Математика | Тела Платона, шар, цилиндр, конус, формула Эйлера; доска графиков с параметрами |
| Физика | Гравитация Земли, Луны, Марса, Юпитера и невесомость; опыт с падением; маятник |
| Химия | Таблица Менделеева (20 элементов); реактор, где из атомов собирают 9 молекул |
| Биология | Модель клетки с органоидами, модель ДНК, игра «Пищевая цепь» |
| Космос | Солнечная система, весы на разных планетах, запуск ракеты |
| Обществознание | Игра «Бюджет на месяц», галерея понятий: семья, государство, право, экономика, культура, образование |
| Логика | Ханойская башня (3–5 дисков), числовые последовательности по уровню класса |
| История России | Лента времени до 1991 года (20 событий), галерея учёных |

Встроенные тесты: 5 вопросов из банка по уровню класса — 1–4, 5–6, 7–8 и 9–11 (`js/questions.js`, около 200 вопросов).

## Конструктор тестов

Страница учителя → «Конструктор тестов». Тест задаётся названием, комнатой (или «Тесты учителя» для холла), диапазоном классов и вопросами с 2–4 вариантами ответа. Можно начать с копии встроенных вопросов. В VR тест появится в выбранной комнате у учеников подходящих классов.

## Баллы

По каждому предмету берётся лучший результат в процентах × 50 (5 из 5 = 50 баллов). Каждое открытие в комнатах даёт ещё 2 балла. Предмет считается сданным при 60% и выше.

## Сервер на Raspberry Pi

`server/app.py` — Python 3 без сторонних библиотек, база SQLite в `/data`. Запускается в Docker-контейнере `python:3.12-alpine`. Ключи создаются при первом запуске в `/opt/vr-lesson-data/keys.json`:
- `teacher` — для страницы учителя (полный доступ);
- `device` — для шлемов (ученики, результаты, открытия).

Как это работает: каждый браузер хранит данные у себя и при наличии связи обменивается ими с сервером. Ученики, тесты и настройки обновляются по правилу «побеждает последняя правка», результаты объединяются, удалённое не возвращается. Без интернета шлем работает как обычно и отправит данные позже.

Сайт открыт по HTTPS, поэтому и адрес сервера нужен с HTTPS. Самый простой путь — Tailscale Funnel на Pi.

Обновление сервера: `cd /opt/vr-lesson-app && git pull && docker restart vr-lesson-api`. Резервная копия — файл `/opt/vr-lesson-data/vrlesson.db`.

## Файлы

- `index.html`, `css/style.css`, `js/app.js` — стартовый экран и сеанс ученика
- `js/engine.js` — движок (WebGL2 + WebXR, панели, физика, ввод)
- `js/rooms.js`, `js/rooms2.js` — комнаты и тесты в VR
- `js/data.js` — материал комнат; `js/questions.js` — банк вопросов. Новые вопросы добавляй в конец списка: от порядка зависят id в статистике.
- `js/store.js` — хранение и синхронизация
- `teacher.html` — страница учителя
- `server/app.py` — сервер синхронизации
- `sw.js` — офлайн-кэш (при смене набора файлов увеличь версию `V`)
- `CHECKLIST.md` — найденные проблемы и как их избегать
