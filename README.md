# VR-урок: первые шаги

Демо для школьников по типу First Steps. Работает в браузере шлема Meta Quest (1, 2, 3) через WebXR. Внешних библиотек нет, всё в одном файле `index.html`. После первой загрузки приложение кэшируется и открывается без интернета.

## Что внутри

1. **Хватай и бросай.** На столе кубики и шарики. Поднеси руку, нажми хват (боковая кнопка) или курок, отпусти кнопку и предмет полетит.
2. **Красная кнопка.** Нажимается рукой или лучом с курком. Меняет цвет лампы, запускает конфетти, звучит сигнал.
3. **Солнечная система.** Наведи луч на планету или Солнце и нажми курок: появится название и факт. Повторное нажатие закрывает карточку.

Управление:
- стик вперёд и отпустить: телепорт в место, куда указывает луч (зелёный круг, красный: нельзя);
- стик влево или вправо: поворот на 30°;
- можно ходить физически, если позволяет границы комнаты.

## Как запустить на шлеме

Нужен адрес `https` или `localhost`: WebXR и офлайн-кэш на обычном `http` не работают.

### Вариант 1. GitHub Pages (подходит, если нет кабеля)

1. Создай на github.com новый репозиторий, например `vr-lesson`, и загрузи в него файлы из этой папки (кнопка Add file → Upload files).
2. Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту-две страница будет доступна по адресу `https://ИМЯ.github.io/vr-lesson/`.
4. Открой этот адрес в Meta Quest Browser и нажми «Войти в VR».

### Вариант 2. Через ПК и кабель (полностью без внешнего хостинга)

Нужны Python и adb (есть в SideQuest или в Android Platform Tools), на шлеме включён режим разработчика и разрешена отладка по USB.

Запуск сервера. **ПК (PowerShell)**, в папке с файлами, копировать целиком:

```
python -m http.server 8080
```

Проброс порта. **ПК (PowerShell)**, во втором окне, копировать целиком:

```
adb reverse tcp:8080 tcp:8080
```

В Meta Quest Browser открой `http://localhost:8080` и нажми «Войти в VR».

## Проверка офлайна

1. Открой страницу один раз при подключённом интернете и подожди пару секунд.
2. Закрой браузер, отключи Wi-Fi и открой тот же адрес снова. Страница должна загрузиться.
3. Для вариантов 1 и 2 адрес должен быть тем же, с которого было первое открытие.

## Проверка без шлема

Открой `index.html` через локальный сервер на ПК. Включится режим просмотра: мышь (зажать) для осмотра, W A S D для движения. Взаимодействие руками доступно только в VR.

## Обновление

В `sw.js` используется схема «сначала кэш, потом обновление в фоне»: после изменения файлов новая версия появится при следующем открытии.

## Ограничения

- Проверено на имитации WebGL и WebXR (логика, физика, телепорт, поворот, выбор объектов). На живом шлеме нужна первая проверка.
- Графика упрощена под слабое железо Quest 1: мало полигонов, без теней и текстур.
- Режим руками (hand tracking) не поддерживается, нужны контроллеры.
