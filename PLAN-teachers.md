# План: учителя-предметники, планшеты, приглашения (запрос Айрата 28.10.2026)

## Проблема
Сейчас у класса один владелец (`classes.teacherId`), учитель видит и ведёт только свои классы (ROLES §4.3, Б41, `class_in_scope`).
Информатику у 5Б ведёт не классный руководитель и не регистратор учёток — доступа у него нет.

## Модель (предложение, нужен «да» Айрата: правка Б41 и ROLES §4.3)
- Владелец класса (классный руководитель / регистратор) — как сейчас: учётки, пароли, состав, архив.
- Новая таблица `class_teachers(class_id, user_id, subject, since, by)` — «ведёт уроки в классе».
  Назначает владелец класса или директор школы; снимает он же; всё в аудит.
- Права предметника: видеть список и статистику учеников этого класса; открывать урок (сессию) с этим классом; указка, сбор, заморозка.
  НЕ может: менять пароли, состав, архивировать, удалять, менять настройки класса.
- Срез прав: `sc['tch']` расширяется классами из class_teachers; отдельный флаг `teach_only` для запретов записи.

## Выбор класса в начале урока
- Планшет учителя / стартовый экран учителя: список «Мои классы» (свои + где предметник), выбор класса и (опц.) предмета → открывается сессия урока (`session.open`), ученики входят по своему коду.
- Можно сменить класс посреди дня без перелогина.

## Планшет ученика (в любой комнате)
Профиль, баллы, пройденные комнаты, свои результаты; сравнение с классом — только обезличенно (место, среднее, свой процент), чужие имена не показываем. Данные только по ключу шлема + своему ученику.

## Планшет учителя
Во всех комнатах: класс, статистика учеников выбранного класса, указка, сбор/заморозка; в своей созданной комнате — вкладка «Редактор» (правка комнаты).

## Админка
В приглашении учителя — выбор региона и района (поля есть у школ, `region`, `district`), проверка прав выдавшего.

## Шаги
1. Т1 (★Opus): закон Б41/ROLES + миграция class_teachers + scope + тесты на реальных данных.
2. Т2: админка — назначение предметников; регион/район в приглашении.
3. Т3: выбор класса при входе учителя (экран + планшет).
4. Т4: планшет учителя: статистика класса, редактор в своей комнате.
5. Т5: планшет ученика: профиль/статистика/сравнение.
